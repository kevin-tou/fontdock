How to

Three commands. Then Cursor.

1. npx fontdock@latest init --inject — skill, registry, toolbar in the layout.

2. Start the dev server. Mix faces on the bar. Hit Done to copy the apply prompt.

3. Paste it in Cursor (or type /fontdock). After fonts are written: npx fontdock uninstall.

Collapse the bar anytime with Ctrl+Shift+F.

FAQ

Before you run init.

Does apply write CSS into my repo?

No. npx fontdock apply and Done copy a prompt. Cursor writes the fonts for your stack, then you uninstall.

Will the toolbar ship to production?

It is injected for local preview. Run npx fontdock uninstall when you are done — layouts and public/__fontdock go away.

Which licenses are in the registry?

Fontshare (commercial-open), Google Fonts OFL, Open Foundry OFL. No personal-use-only files.

How do I start on an existing site?

npx fontdock@latest init --inject, start the dev server, refresh, mix, Done, paste in Cursor.
